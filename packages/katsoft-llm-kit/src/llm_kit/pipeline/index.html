Stage orchestration and durable execution for LLM-in-the-loop batch pipelines: single-pass and convergence-loop shapes, the SQLite-backed run store with its prepare/finalize lifecycle and versioned worker protocol, and post-hoc analysis through audit, provenance, and corpus mining.

The pipeline subsystem turns batch LLM work into resumable, durable runs. Its core abstractions are the Stage protocol (a pure function over a store) and the two shapes built on it: a single-pass fold that runs each stage once, and a convergence loop that repeats grade, select, apply, fill until a progress gate returns a terminal verdict. The execution plane below is a SQLite-backed store with atomic claims, monotonically increasing fencing tokens, and a prepare/finalize controller that brackets a run. A versioned JSON worker protocol lets an out-of-process worker claim units, submit text, and report failures through a uniform envelope. Post-hoc analysis mines finished runs for audit trails, provenance, and corpus patterns.

Where to start

Open packages/katsoft-llm-kit/src/llm_kit/pipeline/core/__init__.py first: its module docstring maps both pipeline shapes, the shared stage protocol, and every deliberate deviation from the source skeleton. For the durable run plane, packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/__init__.py is the equivalent map of the store, controller, adapter, and protocol layers.

Routes

  • Tracked run lifecycle
    1. packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/controller.py prepare_run
    2. -> inline driver run_wave
    3. packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/controller.py finalize_run
  • Convergence drive
    1. packages/katsoft-llm-kit/src/llm_kit/pipeline/core/convergence_loop.py run
    2. -> per cycle: grade, select, apply, fill
    3. packages/katsoft-llm-kit/src/llm_kit/pipeline/core/convergence.py gate verdict (CONVERGED / STALLED / FAILED)

Stage protocol and pipeline shapes

  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/stage.py -- the Stage protocol and compose fold; every pipeline shape is a composition of stages
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/single_pass.py -- single-pass entry point, per-unit deterministic seeding, and gate re-exports
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/convergence_loop.py -- the grade-select-apply-fill cycle with observers, driven to a verdict
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/convergence.py -- convergence gate: CONVERGED, STALLED, FAILED, or CONTINUE from a round history
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/gate.py -- pre-generation Gate shape and run_gates; first-firing gate short-circuits
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/workunit.py -- pluggable work-unit strategies: graph-walk with per-node context or flat-chunk batching
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/cell_policy.py -- consumer-owned cell classification tallied into convergence rounds
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/core/seed.py -- deterministic seeding from a stable identifier so stochastic decisions never churn freshness hashes

Durable run store and controller

  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/store.py -- SQLite-backed ExecutionStore: runs, units, attempts, claims, leases, interrupts
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/model.py -- record dataclasses, the unit state machine, and the error taxonomy
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/controller.py -- prepare_run / finalize_run / unfinished_units; the prepare/finalize lifecycle and halt handling
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/adapter.py -- RunAdapter: the consumer's four-responsibility worker contract plus incompatible-resume refusal
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/status.py -- bounded RunStatus digest: counts, ages, throughput, capped failure groups; never carries prompts or payloads

Worker protocol and event projection

  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/protocol.py -- versioned JSON worker protocol (prepare, claim, submit, fail, finalize, etc.) as mountable handlers
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/events.py -- read-side projection of the attempt log into execution events; interrupt events under schema v2

Scheduling and operational guards

  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/scheduler.py -- in-memory DAG scheduler with capacity, deferred priority, and a thread-pool runner
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/parallel_graph.py -- ParallelGraphStrategy: explicit per-unit dependencies run up to capacity at once
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/deadlines.py -- per-unit wall-time budget, run-wide deadline circuit, and atomically-written deadline notes
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/failure_cache.py -- negative cache of deterministic failures keyed by attempt key; a changed key is a miss
  • packages/katsoft-llm-kit/src/llm_kit/pipeline/execution/interrupts.py -- interrupt rules: probes, adapters, and read helpers over the shared interrupt contract

Post-hoc analysis

Three subdirectories cover what a finished run leaves behind. Audit reports and reasoning chains record per-call decisions and model content. Provenance tracks the chain of transformations from raw input to final artifact. Corpus mining extracts open-label patterns from accumulated output. These are read-only over the durable store and never write back.

Support seams

packages/katsoft-llm-kit/src/llm_kit/pipeline/core/vcs_seam.py defines the VcsBackend protocol (open_for_edit, add, make_changeset, etc.) that the artifact delivery layer drives. The validate subdirectory supplies the ValidationSpec and contract types that the adapter and protocol resolve. The runtime subdirectory provides the LLMBackend transport, submit_validated, and evaluate_submission. The drivers subdirectory holds the inline concurrency-one driver that executes a prepared wave through the store.
