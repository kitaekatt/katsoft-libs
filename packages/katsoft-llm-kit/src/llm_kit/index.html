Multi-backend LLM completion protocol (OpenRouter, Claude, Codex, OpenCode), endpoint and model registry, dispatch and execution, front-door API, graph viewer, CLI, and deployment-mode runtime with bootstrap provisioning guards

This library provides one shared protocol with four backend transports -- OpenRouter HTTP, Claude CLI, Codex CLI, and OpenCode CLI -- plus the layers that resolve a named endpoint and model, pace the call, and execute it with halt-and-resume semantics. The contract sits at the seam between what a caller asks for and what a transport does; every transport below that seam is a concrete integration. Deployment provenance is explicit: source, legacy, and package modes each route shared contracts differently, and an ambiguous environment raises rather than guesses. Batch pipeline orchestration lives one level down with its own page.

Where to start

Open packages/katsoft-llm-kit/src/llm_kit/adapters/backends.py to see how the OpenRouter and Claude transports build a request, track dropped parameters, and classify failures into the shared halt taxonomy. The completion package's type definitions define the response shape every transport returns.

Routes

  • Build an OpenRouter client and complete
    1. packages/katsoft-llm-kit/src/llm_kit/adapters/client.py -- resolve the endpoint, build the OpenAI client
    2. packages/katsoft-llm-kit/src/llm_kit/adapters/backends.py -- OpenRouterBackend.complete issues the call and normalizes the result
  • Compose and run a Codex exec call
    1. packages/katsoft-llm-kit/src/llm_kit/adapters/codex_command.py -- build the sanctioned argv with absolute paths and sandbox flags
    2. packages/katsoft-llm-kit/src/llm_kit/adapters/codex_backend.py -- CodexCliBackend.complete drives the subprocess and reads the result file
  • Terminate a swapper-managed model
    1. packages/katsoft-llm-kit/src/llm_kit/adapters/swapper.py -- locate and verify the model PID against the swapper process
    2. packages/katsoft-llm-kit/src/llm_kit/adapters/_swapper_process.py -- re-check create_time, send SIGTERM, escalate to SIGKILL if needed
