The llm_kit core library: the completion protocol and its four provider backends (OpenAI-compatible HTTP, Claude CLI, Codex CLI, OpenCode CLI), dispatch routing, the front-door API, the graph viewer, the CLI, and the deployment-mode runtime.

The core library behind the katsoft-llm-kit package. Every LLM completion this repository sends or receives passes through one shared protocol, and the four provider transports -- OpenAI-compatible HTTP, the Claude CLI, the Codex CLI, and the OpenCode CLI -- are concrete implementations of that protocol. A routing layer selects which transport handles a call, and a public API is what external callers import. An interactive visualizer, a command-line interface, and job and run schemas round out the surface. Three of the largest sub-areas -- batch pipeline orchestration, the endpoint registry, and the relay clients -- carry their own orientation pages and are linked from the navigation.

Where to start

Open the packages/katsoft-llm-kit/src/llm_kit/completion types first: they define the response shape, the halt taxonomy, and the capability record that every backend returns or raises. The packages/katsoft-llm-kit/src/llm_kit/adapters directory shows how each transport builds its request and parses the result.

Deployment and runtime

  • packages/katsoft-llm-kit/src/llm_kit/_runtime.py -- Determines whether this copy is a source tree, a legacy plugin link, or an installed wheel; routes shared contracts and refuses ambiguous environments.
  • packages/katsoft-llm-kit/src/llm_kit/_deployment.py -- Marker file rewritten by a build hook with release identity for the package wheel.
  • packages/katsoft-llm-kit/src/llm_kit/bootstrap_guard.py -- Vendored guard that detects whether the bootstrap plugin has provisioned this plugin and re-execs under the correct venv interpreter.

Provider backends

  • packages/katsoft-llm-kit/src/llm_kit/adapters -- The four concrete backends, their command builders, the shared streaming runner, capability records, and account and endpoint probes. Open this directory when adding or debugging a transport.

Completion protocol

  • packages/katsoft-llm-kit/src/llm_kit/completion -- Shared types, halt taxonomy, capability framework, output contracts, and session types that every backend implements against.

Routing and public surface

  • packages/katsoft-llm-kit/src/llm_kit/dispatch -- Backend factory selection, pacing policy, and reachability checks.
  • packages/katsoft-llm-kit/src/llm_kit/frontdoor -- The public API that external callers import.
  • packages/katsoft-llm-kit/src/llm_kit/cli -- Command-line entry points.

Graph viewer
